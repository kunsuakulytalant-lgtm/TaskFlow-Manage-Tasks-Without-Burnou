# TaskFlow

Promo landing page for a task planning mobile app. Built with semantic HTML, CSS Grid and Flexbox, mobile-first, no JavaScript frameworks.

- Header with adaptive navigation and a pure CSS burger menu
- Hero with device mockup and background media
- Feature and tariff cards in a responsive grid
- Closed beta form with pure CSS validation
- Footer with links, legal block and a dark theme switch

Open `index.html` in a browser to view the page.
